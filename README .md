# UniCal

大学生向けのスケジュール管理アプリのプロトタイプです。授業・課題・出欠・プライベートの予定をひとつにまとめ、先生との面談予約やゼミ生の気分共有もできます。

`index.html` 1ファイルで動きます。Firebase（Google の無料データベース）につなぐと、別のスマホやパソコンの間でデータが共有されます。つながない場合は「ローカルモード」で動き、データはそのブラウザだけに保存されます。

## Firebase につなぐ手順

1. https://console.firebase.google.com を開き、Google アカウントでログインして「プロジェクトを作成」を押します。名前は自由です（例：unical）。Google アナリティクスはオフで構いません。
2. 左のメニューの「構築」→「Firestore Database」→「データベースを作成」を押します。場所は `asia-northeast1（東京）` を選び、「本番環境モード」で作成します。
3. Firestore の「ルール」タブを開き、中身を下のルールに書き換えて「公開」を押します。
4. プロジェクトの概要の横の歯車 →「プロジェクトの設定」を開き、下の「マイアプリ」でウェブ（`</>` のマーク）を選んでアプリを登録します（Hosting の設定は不要です）。
5. 表示された `firebaseConfig` の中の値（apiKey、authDomain、projectId、storageBucket、messagingSenderId、appId）を、`index.html` の上のほうにある `FIREBASE_CONFIG` の `""` の中にそれぞれ貼り付けます。
6. `index.html` を GitHub にアップロードし直します。最初に誰かが開いたときに、サンプルデータが自動で入ります。

### Firestore のルール

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /unical/{docId} {
      allow read, write: if true;
    }
  }
}
```

## 主な機能

- ログイン／新規会員登録（学生、または登録コードを持つ先生）
- 今日の予定、今日のToDo、締切アラート、今日の気分
- 月カレンダー（大学／プライベートの切り替え、日付を選ぶと下に内容を表示）
- 時間割と科目ごとの出席率（70%を下回ると警告）
- 課題は一人ひとり別に管理（ほかの人の課題は表示されません）
- 先生の空き時間から面談を予約、先生側で承認・日時変更・お断り
- 先生とのトーク、ゼミのグループトーク
- ゼミ生の気分を先生と共有、7日続けて「しんどい」で先生にアラート
- ユーザーIDで友達を検索、友達の空きコマを表示
- ほかの端末での変更（申し込み、トーク、友達申請など）がすぐに画面に反映

## ログイン状態について

ログインは開いているタブの中だけ続きます。ページを閉じて開き直すと、ログイン画面から始まります。同じ端末を何人かで使うときは、使い終わったらメニューからログアウトしてください。表示テーマ（ライト／ダーク）は端末ごとに保存されます。

## サンプルデータに戻す

Firebase につないでいるときは、全員のデータが消えてしまうので、メニューに「サンプルデータに戻す」は表示されません。戻したいときは、URL の最後に `?admin` を付けて開いてください（例：`https://ma1oo.github.io/UniCal/?admin`）。サンプルデータの日付（課題の締切など）は、データが入った日を基準にしているので、日がたったら戻すと見やすくなります。

## 注意

プロトタイプのため、ログインのしくみは簡易的です。データベースは URL を知っている人なら誰でも読み書きできる設定で、パスワードも暗号化せずに保存しています。本物のパスワードや個人情報は入力しないでください。本番では Firebase Authentication などを使った認証と、人ごとに読み書きを制限するルールが必要です。

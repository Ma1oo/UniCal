# UniCal

大学生向けのスケジュール管理アプリのプロトタイプです。授業・課題・出欠・プライベートの予定をひとつにまとめ、先生との面談予約やゼミ生の気分共有もできます。

`index.html` 1ファイルで動きます。サーバーやビルドは不要です。

## 主な機能

- ログイン／新規会員登録（新規登録は学生のみ。先生アカウントは大学が発行する想定）
- 今日の予定、今日のToDo、締切アラート、今日の気分
- 月カレンダー（大学／プライベートの切り替え、日付を選ぶと下に内容を表示）
- 時間割と科目ごとの出席率（70%を下回ると警告）
- 先生の空き時間から面談を予約、先生側で承認・日時変更・お断り
- 先生とのトーク、ゼミのグループトーク
- ゼミ生の気分を先生と共有、7日続けて「しんどい」で先生にアラート
- ユーザーIDで友達を検索、友達の空きコマを表示

## 注意

プロトタイプのため、データはブラウザの localStorage に保存されます。パスワードも暗号化せずに保存しているので、本番ではサーバー側での認証が必要です。
